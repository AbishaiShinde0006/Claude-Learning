Chat

Best for brainstorming, asking questions, and handling everyday tasks quickly.
Convenient for quick back-and-forth interactions.
Web search can be enabled for real-world, up-to-date information.


Cowork

Use this when you want Claude to handle repetitive or research-heavy work so you can focus on higher-value, human-intensive tasks.
Example: gathering information from 50+ sources, including ones without an API that are difficult to access manually.
Can be given access to your files, browser, and screen — it operates your computer the way you would.
You can set constraints on how much access Claude has.


Code

Your autonomous coding partner.
Give it access to a file directory and it will develop entire software projects within that directory.
Can be connected to GitHub via the GitHub connector to access specific repositories.
Runs autonomously for extended periods without you needing to watch it actively.

Three modes in Claude Code:

Ask — Claude handles development but requests your approval before making each change.
Plan — Claude presents a full plan before writing any code; you can review and modify before it proceeds.
Auto — Claude does everything autonomously but always asks before running terminal commands.
