Projects in Claude
There are 3 steps to leverage the power of Projects:
Step 1 — Create a Project
Create a new project and give Claude information about it, like what you're trying to achieve and what your goal is.
Step 2 — Give Instructions
There's a separate box where you can add custom instructions on how Claude should approach the work, what tone to use, etc.
Step 3 — Provide a Project Base
Here you provide the files needed to complete the project more effectively. You can share files, Google Drive, etc.

Using Claude Projects for Work
If you're using Claude Projects in a team, there are 3 roles:
Can Edit — Selected people in your group can make changes to the project.
No Edit — Read only access. They can view but not change anything.
Owner — This person has full control over the entire project.
