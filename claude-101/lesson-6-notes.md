What are Artifacts?
Artifacts are outputs that appear on the right side of your screen. Instead of cramping long code, lengthy text, or visual outputs into the chat window, Claude displays them separately in the artifact panel for a cleaner experience.

When does Claude use an Artifact?
Claude will use an artifact when:

The output is a text document longer than 15 lines
It is something complex that stands on its own
It is something you will reuse, iterate on, or make changes to in the future
It is a visual representation, such as a diagram or flowchart


6 Types of Artifacts

Text — Long-form written content that needs its own space, e.g. reports, notes, drafts
Code — Code for anything from a small script to a full project
Web page — A rendered webpage so you can see the front-end visually, along with the underlying back-end code
Mermaid diagram — Flowcharts, org charts, sequence diagrams and more, generated from a text description
SVG image — Scalable vector graphics; clean, sharp images that don't pixelate when resized
React component — Interactive UI elements that users can actually interact with, not just view


How to Share Artifacts

Share via a link — the recipient can access it even without a Claude account
If using Claude for Work, share directly with teammates so they can view it within the workspace
