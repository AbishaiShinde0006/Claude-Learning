What are Skills?
Claude has broad general knowledge, but Skills tell it the how — the exact workflow and process to follow for a specific task. They turn a generalist into a specialist for tasks you repeat regularly.

How to Create a Custom Skill

Start a new conversation with Claude
Tell Claude you want to create a new skill and describe what it should do
Answer Claude's questions about the workflow and what good output looks like
Upload any reference materials — templates, examples, style guides
Claude generates and saves the skill file for you — no coding needed

Once saved, Claude automatically invokes the skill whenever you work on a relevant task. No manual triggering needed.

Skills vs Projects
Projects: Give Claude information and context
Skills: Tell Claude how to perform a task
